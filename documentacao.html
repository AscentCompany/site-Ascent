Ascent — Apache POI & AWS S3

Como o projeto lê planilhas .xlsx do Amazon S3, extrai dados estruturados e os persiste no MySQL via Spring JDBC.

🗺️ Visão Geral do Fluxo

O sistema importa automaticamente a base de voos da ANAC. Os arquivos .xlsx ficam particionados em um bucket no Amazon S3. A aplicação baixa cada parte, lê célula a célula usando Apache POI no modo StAX streaming (sem carregar o arquivo inteiro na memória) e insere os dados no banco MySQL via Spring JDBC.

📚 O que é o Apache POI?

O Apache POI é uma biblioteca Java da Apache Software Foundation que permite ler e escrever arquivos no formato Microsoft Office — como .xlsx, .xls, .docx, entre outros — sem precisar instalar o Office na máquina.

Neste projeto usamos dois artefatos Maven:

ArtefatoPara quê serve
poi Suporte ao formato binário antigo .xls (HSSFWorkbook)
poi-ooxml Suporte ao formato moderno .xlsx (XSSFWorkbook / streaming)

Modo padrão vs. Streaming (StAX)

A forma mais simples de usar o POI é instanciar um XSSFWorkbook — ele carrega a planilha inteira na memória. Para arquivos grandes (como as partes ANAC com centenas de milhares de linhas), isso causaria estouro de memória.

AbordagemMemóriaQuando usar
XSSFWorkbook (padrão) Alta — carrega tudo Arquivos pequenos, leitura simples
XSSFReader + StAX (streaming) Baixa — lê linha a linha Arquivos grandes em produção ✅
ℹ️ O projeto usa o modo StAX streaming via XSSFReader + XMLStreamReader. O arquivo nunca fica inteiro na RAM — cada evento XML (abertura de tag, texto, fechamento) é processado e descartado imediatamente.

🔍 Leitura StAX — LeitorExcel.java

O método extrairDeArquivo(File) é o coração da leitura. Ele abre o .xlsx como um pacote OPC, obtém um iterador de sheets e percorre o XML da primeira sheet evento a evento.

1. Abrir o pacote e obter o leitor de sheet

try (OPCPackage pkg = OPCPackage.open(arquivo, PackageAccess.READ)) {

    XSSFReader    xssfReader    = new XSSFReader(pkg);
    SharedStrings sharedStrings = new ReadOnlySharedStringsTable(pkg);

    SheetIterator sheetIterator = (SheetIterator) xssfReader.getSheetsData();
    InputStream   sheetStream   = sheetIterator.next();
}

O SharedStrings é a tabela de strings compartilhadas do .xlsx: células do tipo s armazenam apenas um índice inteiro que aponta para essa tabela, economizando espaço no arquivo.

2. Loop StAX — evento a evento

XMLStreamReader xml = xmlFactory.createXMLStreamReader(sheetStream);

while (xml.hasNext()) {
    int event = xml.next();

    switch (event) {

        case XMLStreamReader.START_ELEMENT:
            // início de <row>, <c> (célula) ou <v> (valor)
            break;

        case XMLStreamReader.CHARACTERS:
            // texto dentro de <v> — acumula no StringBuilder
            if (inV) currentVal.append(xml.getText());
            break;

        case XMLStreamReader.END_ELEMENT:
            // fim de <v>: resolve shared string se necessário
            // fim de <row>: processa a linha completa
            break;
    }
}

4. Converter referência de célula em índice de coluna

O atributo r de cada célula é algo como "AB12". O método refToColIndex() extrai apenas as letras e converte para índice base-0: 

private int refToColIndex(String ref) {
    int col = 0;
    for (int i = 0; i < ref.length(); i++) {
        char c = ref.charAt(i);
        if (c >= 'A' && c <= 'Z')
            col = col * 26 + (c - 'A' + 1);
        else break;
    }
    return col - 1;
}

5. Converter datas e horas seriais do Excel

☁️ Integração com Amazon S3

O SDK da AWS v2 é usado para baixar os arquivos do bucket. As credenciais são lidas do .env via getEnvOrProp() e injetadas como StaticCredentialsProvider. Se não houver credenciais explícitas, o SDK usa o Instance Profile da EC2 automaticamente. 

public S3Client criarClienteS3(Region regiao) {
    String accessKey    = getEnvOrProp("AWS_ACCESS_KEY_ID", null);
    String secretKey    = getEnvOrProp("AWS_SECRET_ACCESS_KEY", null);
    String sessionToken = getEnvOrProp("AWS_SESSION_TOKEN", null);

    if (accessKey != null && secretKey != null) {
        return S3Client.builder()
            .region(regiao)
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsSessionCredentials.create(accessKey, secretKey, sessionToken)))
            .build();
    }

    // fallback: IAM Role da EC2
    return S3Client.builder().region(regiao).build();
}

Download com prefetch paralelo

Para otimizar a importação de múltiplos arquivos, enquanto o arquivo atual é lido e inserido no banco, o próximo arquivo já está sendo baixado em background por uma thread dedicada (ExecutorService com uma thread daemon chamada s3-prefetch): 

Future<File> proximoDownload = downloader.submit(
    () -> leitorExcel.baixarDoS3(arquivos.get(0))
);

for (int i = 0; i < arquivos.size(); i++) {

    File tempFile = proximoDownload.get(); // aguarda o atual

    if (i + 1 < arquivos.size()) {
        final String proximo = arquivos.get(i + 1);
        proximoDownload = downloader.submit(
            () -> leitorExcel.baixarDoS3(proximo) // baixa em paralelo
        );
    }

    // lê e insere enquanto o próximo baixa
    ResultadoLeitura dados = leitorExcel.extrairDeArquivo(tempFile);
    inserirDadosNoBanco(dados);
    tempFile.delete();
}
MainApp.java

Cache em memória para evitar duplicatas

Para não consultar o banco a cada linha, o projeto mantém listas paralelas em memória (chave → id) para companhias, aviões e aeroportos. Antes de inserir, verifica na lista; só consulta o banco se não encontrar: 

// verifica no cache local primeiro
if (buscarNaLista(cacheCompanhiasChave, c.codCompanhia) != -1) continue;

// só vai ao banco se não estiver no cache
Integer idExistente = buscarId(
    "SELECT idCompanhia FROM companhia WHERE codCompanhia = ? LIMIT 1",
    c.codCompanhia

🏗️ Entidades Extraídas da Planilha

Cada linha da planilha ANAC origina até 5 entidades que são acumuladas no objeto ResultadoLeitura e depois inseridas em 5 tabelas diferentes, na ordem correta para respeitar as chaves estrangeiras:

[1/5]  Companhia — id_empresa, nm_empresa, nm_pais
[2/5]  Aviao — ds_modelo, nr_assentos_ofertados
[3/5]  Aeroporto — origem e destino por linha
[4/5]  Voo — nr_voo, cd_di, passageiros pagos + grátis
[5/5]  AeroportoDirecao — partida e chegada com data e hora
⚠️ A inserção de AeroportoDirecao usa ON DUPLICATE KEY UPDATE para evitar erro caso a mesma combinação voo + aeroporto + direção já exista no banco.
